# WithYou 引流页内容重写方案

## 目标

把当前落地页从“产品能力介绍”改成“高频聊天卡点诊断页”。用户刷到后应快速产生代入感：这不是泛泛教聊天，而是能判断他当前聊天到底卡在哪里，并给出下一步动作和可直接发送的回复。

## 依据

- 抖音调研报告显示，高频评论痛点集中在冷淡回复、聊崩修复、不知道问题在哪、女生不主动、是否被养鱼、普通低窗口案例不够真实。
- 知识库的 446 人画像显示，最高频问题是迎合讨好、自卑/怂、木讷直男、没主见、内向。
- 场景卡点手册强调“判断优先于话术”：同一句回复在不同窗口下可能是满分，也可能是红线。

## 内容策略

首屏不讲“AI 情感助手”，直接讲用户正在经历的卡点：

> 她只回你“嗯、哦、哈哈”，到底是冷了，还是你不会接？

页面主线：

1. 先让用户看到自己的问题。
2. 再展示 WithYou 会如何判断局势。
3. 最后给出可直接发送的真人回复。

## 可靠性与人设背书

页面必须建立“不是普通工具”的信任感。情感领域没有绝对标准答案，很多判断依赖上下文、经验和模糊信号，因此 WithYou 的卖点不是全自动话术机，而是“多年实战经验沉淀 + AI 半自动迭代 + 人工审核优化”的判断系统。

需要表达的核心：

- 背后有人：来自多年真实学员案例、聊天复盘和实战经验，而不是临时拼出来的话术库。
- 不装全知：关系判断存在不确定性，WithYou 会给出依据、反证和置信度，而不是承诺“这样回一定成”。
- 半自动更新：AI 负责整理高频案例、抽取卡点、生成初版分析；人工负责审核、修正、沉淀可复用规则。
- 持续变准：真实案例会进入复盘和优化流程，错误判断不会被包装成标准答案。

建议页面增加一个“为什么可信”区块，文案方向：

> WithYou 不是全自动话术机。  
> 情感判断本来就没有标准答案，所以我们用 AI 做高频分析和迭代，再由有多年实战经验的人做审核、复盘和优化。它不会告诉你“这样一定赢”，而是告诉你：当前证据更像什么、还有哪些反证、这一步最稳的动作是什么。

## 首页主卡点

保留 8 个高频卡点作为页面核心内容：

1. 她回复很冷淡：嗯、哦、哈哈、还行吧。
2. 已读不回 / 不主动找你：该补一句还是停手。
3. 聊成朋友 / 闺蜜兄弟：聊很多但没有暧昧感。
4. 邀约被拒：最近有点忙，后面再说吧。
5. 聊崩了怎么修：前几天还好，第 6 天情绪低后冷掉。
6. 她是不是养鱼：会回你但不落地见面。
7. 女生给窗口但你不敢推进：主动分享、暗示、抛话题后仍在空聊。
8. 女生情绪来了不会接：累、生病、心情不好时只会讲道理。

每张卡片展示三层信息：

- 用户原话：来自抖音评论或知识库场景的真实表达。
- WithYou 判断：窗口、温度、阶段、风险。
- 下一步动作：推进、接住、回收、停止追问、补救。

## 真实分析素材

实现前必须调用 `withyou-agent` 获取真实输出，不手写假分析。

已有入口：

- 脚本：`scripts/run-real-analysis.mjs`
- 服务：`http://127.0.0.1:18080/v1/chat/completions`
- 模型：`withyou-student`

已有样本可复用：

- 冷淡/疲惫场景
- 暧昧升温场景
- 画像记忆场景
- 邀约被拒场景

需要补跑的样本：

- 已读不回
- 聊成朋友/闺蜜兄弟
- 聊崩修复
- 是否养鱼
- 情绪场景不会接

真人回复展示必须来自 agent 的“真人表达 / 多风格人格生成”输出，不能由页面静态文案伪造。

## 页面结构

1. Hero：强痛点标题 + 一句话价值主张 + 主 CTA。
2. 高频卡点：8 张卡点卡片，优先展示用户原话。
3. 真实分析：展示 4-6 个 agent 原始输出提炼后的案例。
4. 真人回复：展示多风格可直接发回复。
5. 为什么可信：多年实战经验 + AI 半自动迭代 + 人工审核优化。
6. 为什么有效：强调先判断窗口、温度、阶段和禁忌动作，再给话术。
7. CTA：把聊天发给 WithYou 看看卡在哪。

## 实现范围

最小改动：

- 复用现有 React 组件和视觉风格。
- 调整页面顺序，把卡点和真实分析提前。
- 改文案和案例数据，不新增复杂交互。
- 如有必要，只新增一个简单数据数组文件或在组件内定义数据。
- 增加一个轻量可信度区块，不做复杂导师个人页。

暂不做：

- 不做在线上传组件。
- 不做复杂轮播。
- 不做埋点。
- 不做新设计系统。
- 不新增依赖。

## 验收标准

- 首屏 3 秒内能看出页面解决“聊天卡点判断”问题。
- 页面至少包含 8 个高频卡点。
- 真实分析案例来自 `withyou-agent` 输出。
- 真人回复区使用 agent 生成结果。
- 页面明确表达“多年实战经验 + AI 半自动迭代 + 人工审核优化”。
- 页面不承诺情感问题有标准答案，不做“必成”暗示。
- `npm run build` 通过。
